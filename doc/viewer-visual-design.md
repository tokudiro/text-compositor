# Obunzu: 見た目の方針（#192）

Obunzu（Viewer。[#165](https://github.com/tokudiro/text-compositor/issues/165)）の見た目の方針を、色・余白・フォント・部品ごとにまとめる。実装は、`viewer/src/chrome/chrome.css`（ウィンドウ本体）と、`text_compositor/html_output.py`の`DOCUMENT_CSS`（文書）にある。

## 基本の考え方

- **小さく詰まった、フラットな見た目**にする（ボタンは高さが小さく、枠なしで、角丸は小さい）。閲覧が目的のため、道具の主張を弱くし、文書を主役にする。
- **ライトとダークの両方**に対応する。既定は、OSの設定に従い、設定画面で、ライト・ダークに固定できる（`VIEWER_THEME`の環境変数は、確認用で、設定より優先する）。
- **アクセント色は、OSの設定に左右されず、固定する**（青。ライトは`#0078d4`、ダークは`#4ca0e8`）。
- **文字は、読める濃さにする**。文書のalertの見出しなど、本文と同じ大きさの文字は、背景とのコントラスト比が**4.5:1以上**（WCAG 2.1のAA）であることを、テスト（`tests/test_html_output.py`の`TestDarkColors`）で確認する。

## 色

ウィンドウ本体（ツールバー・帯・設定画面・案内の画面）。

| 用途 | ライト | ダーク |
|------|--------|--------|
| 文字 | `#1f2328` | `#e6edf3` |
| 背景（文書の背景と同じ） | `#ffffff` | `#0d1117` |
| ツールバー・帯の背景 | `#f8f8f8` | `#151b23` |
| 区切り線 | `#e0e0e0` | `#3d444d` |
| 補助の文字 | `#59636e` | `#9198a1` |
| ボタンのホバー | `#e6e6e6` | `#262d36` |
| アクセント／その薄い背景 | `#0078d4`／`#dcebf8` | `#4ca0e8`／`#223b52` |
| エラーの帯（背景／文字） | `#fde7e9`／`#a4262c` | `#442726`／`#f1b0b4` |
| 警告の帯（背景／文字） | `#fff4ce`／`#7a5a00` | `#433519`／`#f5d77a` |

- ダークのツールバーの背景は、文書のコードの背景（`#151b23`）と同じにして、文書との一体感を出す。以前は、色味が違っていた（`#1b1b1b`）。
- 文書のalertの色は、ライトが`#0969da`（Note）・`#1a7f37`（Tip）・`#8250df`（Important）・`#9a6700`（Warning）・`#d1242f`（Caution）。ダークは、暗い背景で読めるように、`#4493f8`・`#3fb950`・`#ab7df8`・`#d29922`・`#f85149`にする（コントラスト比は、ライトの色のままだと3.3〜3.6だったが、5.2〜6.9になる）。

## 余白と大きさ

- ツールバー: 高さ40 px以上、左右の余白10 px。ボタンは、高さ28 px。アイコンのボタンは、28 px角で、アイコンは18 px。
- 設定画面: 幅720 pxの列に、見出しの行と項目の行を揃える。項目は、「名前と説明」（左）と「選択肢」（右）の行で、行の余白は、上下16 px。
- 文書: 本文の幅は、約860 px（`html_output.py`のCSS）。行間は1.6。

## フォント

- **ウィンドウ本体**: `Segoe UI`、`Yu Gothic UI`、`Hiragino Sans`、`system-ui`の順。13 px。
- **文書**: `Noto Sans JP`、`Segoe UI`、`Hiragino Sans`、`Yu Gothic UI`の順。16 px。等幅は、`Cascadia Mono`・`Consolas`。
- **Noto Sans JPは、Viewerに同梱しない**。PDF出力（Typst）では、フォントを取得して使うが、Viewerでは、OSにあるフォントを使う。同梱すると、配布サイズが増え、起動にも影響する可能性があるため、必要が出るまで見送る（判断の記録。表示が気になる環境が出たら、再検討する）。

## アイコン

- 線のアイコン（24 pxの座標で、線の太さ1.8、端と角は丸い）。色は、文字色に従う（`currentColor`）ため、ライトでもダークでも見える。意味とショートカットは、ホバー（`title`）で表示する。`aria-label`とキーボードのフォーカスも保つ。
- アプリのアイコンは、`viewer/assets/icon.svg`（[#193](https://github.com/tokudiro/text-compositor/issues/193)）。案内の画面には、置かない（画像の読み込みで、起動時に、ちらつくため。#192の確認後の判断）。

## 画面ごとの方針

- **ツールバー**: 左に、ファイルの操作（開く・再読み込み・自動で更新）と、ファイルの場所（ファイル名を太字で主に、フォルダは補助の色で）。右に、状態、拡大縮小、設定（歯車）。上下の位置は、設定で切り替える。
- **エラー・警告**: 帯は、1行の要約。詳細は、一覧に出す。エラーは赤、警告は黄で、印と左の線の色で見分ける（[#202](https://github.com/tokudiro/text-compositor/issues/202)）。
- **設定画面**: 見出しを左、閉じるボタンを右端に置く。選択肢が少ない項目は、横のセグメント（切り替えボタン）にする。増えた場合は、行を足す。
- **案内の画面**（何も開いていないとき）: 案内の文、「ファイルを開く…」のボタン、ドラッグ＆ドロップとショートカットの案内を、中央に置く。ファイルをドラッグしている間は、破線の枠で、受け付けることを示す。
- **ウィンドウ**: 大きさ・位置・最大化を、前回のとおりに戻す。位置が、今のどの画面にも収まらないときは、大きさだけを戻す。

## 起動時の見た目

- ウィンドウと内容のビューの背景を、ページの背景色に合わせ、白い画面が見える時間を短くする（[#180](https://github.com/tokudiro/text-compositor/issues/180)）。
- このPRの変更（アイコンの画像の読み込みなど）で、起動が遅くなっていないことを、#180の計測（`benchmarks/html-view/measure-visual.ps1 -Tool viewer`）で確認した。「起動から画面が落ち着くまで」は、平均0.88秒（0.82〜0.92秒）で、変更前の0.86秒（0.82〜0.92秒）と同じ範囲だった。

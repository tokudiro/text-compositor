# finiteのギャラリー

`finite`が対応する図の種類の実例です（[#291の対応表](08_diagrams.md#記法で描ける図の種類対応表)）。記法の説明は「図表」の章の「finiteについて」を参照してください。

## 状態遷移図（DFA）

2進数で、3の倍数を受け入れるDFAです。`q0`が開始状態で、受理状態でもあります（二重丸）。

```finite
(
  q0: (q0: "0", q1: "1"),
  q1: (q2: "0", q0: "1"),
  q2: (q1: "0", q2: "1"),
),
initial: "q0",
final: ("q0",)
```

## 状態遷移図（ε遷移つきのNFA）

複数のラベルは、`"a,b"`のように、1つの文字列にします。遷移のない状態は、`none`と書きます。

```finite
(
  q0: (q0: "a,b", q1: "a"),
  q1: (q2: "b"),
  q2: (q3: "ε"),
  q3: none,
),
initial: "q0",
final: ("q3",)
```

## 配置を変える

`layout: layout.circular`で、状態を円形に並べます。

```finite
(
  q0: (q0: "a,b", q1: "a"),
  q1: (q2: "b"),
  q2: (q3: "ε"),
  q3: none,
),
initial: "q0",
final: ("q3",),
layout: layout.circular
```

## 日本語の状態名とラベル

状態名もラベルも、日本語で書けます。状態名は、`"待機"`のように、引用符で囲みます。

```finite
(
  "待機": ("実行中": "開始"),
  "実行中": ("完了": "終了", "実行中": "再試行"),
  "完了": none,
),
initial: "待機",
final: ("完了",)
```

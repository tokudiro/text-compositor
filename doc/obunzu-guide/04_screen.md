# 画面の見方と操作

![ライトの配色|width=100%](images/main-light.png)

## ツールバー

画面の上（設定で、下にもできます）に、ツールバーがあります。左から順に、次のボタンと表示が並びます。

| 部品 | 意味 |
| --- | --- |
| フォルダのボタン | ファイルを開きます（`Ctrl+O`） |
| 回転する矢印のボタン | もう一度、変換します（`F5`・`Ctrl+R`）。ファイルを開いていないときは、押せません |
| 稲妻のボタン | 「保存したら自動で更新」の、オン・オフ。オンのとき、色が付きます |
| 表のボタン | CSVを開いているときだけ、出ます。1行目を、見出しにするかを、切り替えます |
| ファイル名と、フォルダ | 開いているファイル |
| 「変換中…」 | 変換している間だけ、出ます |
| 更新した時刻と、かかった時間 | 例: `00:02:58 更新 207 ms` |
| `−`・拡大率・`＋` | 縮小・拡大。拡大率を押すと、実寸（100%）に戻ります |
| 歯車のボタン | 設定を開きます（`Ctrl+,`） |

ボタンに、マウスを重ねると、名前とショートカットキーが出ます。

## ショートカットキー

| 操作 | キー |
| --- | --- |
| ファイルを開く | `Ctrl+O` |
| もう一度、変換する | `F5`・`Ctrl+R` |
| 前の文書へ戻る・進む | `Alt+←`・`Alt+→`（ツールバーの「戻る」「進む」のボタンでも、できます）。文書の中のリンクをたどったあとや、別のファイルを開いたあとに、使えます。前のスクロール位置に戻ります |
| 文書の中を検索する | `Ctrl+F`（閉じるのは、`Esc`）。一致した所は黄色、今の一致はオレンジで示し、件数を出します。`Enter`・`Shift+Enter`で、次・前の一致へ移ります。正規表現・大文字小文字の区別も、切り替えられます |
| 拡大 | `Ctrl`＋`+`、または`Ctrl`＋マウスホイール |
| 縮小 | `Ctrl`＋`-`、または`Ctrl`＋マウスホイール |
| 実寸に戻す | `Ctrl+0` |
| 設定を開く・閉じる | `Ctrl+,`（閉じるのは、`Esc`も使えます） |
| ツールバーと文書の間を行き来する | `F6`（キーボードだけで、ツールバーのボタンに届きます） |
| 終了 | `Ctrl+Q` |

メニュー（「ファイル」「表示」）からも、同じ操作ができます。メニューは、ふだんは隠れています。`Alt`キーを押すと、出ます。

## タブ

設定で「複数のタブ」を「使う」にすると、複数の文書を、タブで切り替えて開けます。

| 操作 | 方法 |
| --- | --- |
| 新しいタブで開く | `Ctrl+Shift+O`、またはタブ列の右端の「＋」。いまの文書は、そのまま残ります。`Ctrl`キーを押しながら、ファイルをドロップしても、新しいタブで開きます |
| 切り替える | タブを押す、または`Ctrl+Tab`（次）・`Ctrl+Shift+Tab`（前） |
| 閉じる | `Ctrl+W`、タブ列の右端にある「×」（見ているタブを閉じます）、またはタブの中ボタン（ホイール）クリック。最後の1つは、閉じられません |

- タブ列は、タブが2つ以上あるときだけ出ます。
- スクロールの位置・検索・戻る進む・保存したときの自動更新は、タブごとに保たれます。見ていないタブの原稿を保存しても、そのタブが、自動で更新されます。
- 変換を行うPythonは、全タブで1つです。片方のタブで、時間のかかる図を変換している間は、もう片方の変換も待ちます。
- 「複数のタブ」を「使わない」に戻すと、いま見ているタブだけを残して、ほかは閉じます。

## 画像を保存する

図や画像を右クリックすると、保存できます。SVGの図は、「画像（SVG）を保存…」（ベクターのまま）か、「画像（PNG）を保存…」（2倍の大きさのPNG）を選べます。SVG以外の画像は、元の形式のまま保存します。保存のダイアログは、文書のフォルダ、または前回に画像を保存したフォルダから始まります。

## 自動で更新

開いているファイルと、そのファイルが参照する画像を保存すると、表示が自動で更新されます。保存から、約0.2秒後です。スクロールの位置は、保たれます。

- お使いのエディタで書きながら、Obunzuを、横に並べて使えます。
- まだ存在しない画像（あとから作る画像）も、作られた時点で、更新します。
- 変換に失敗しても、直前の表示が残り、監視は続きます。原稿を直して保存すると、自動で回復します。
- 稲妻のボタンで、オフにできます。オフにしたときは、`F5`で、変換し直します。

## CSVの見出し

`.csv`を開いているときだけ、ツールバーに、表のボタンが出ます。オンのときは、1行目を見出しにします。オフのときは、すべてをデータの行にします。切り替えは、覚えておきます。

## ダークの配色

![ダークの配色|width=100%](images/main-dark.png)

配色は、設定で、「OSに合わせる」「ライト」「ダーク」から選びます。

## ウィンドウの大きさ

ウィンドウの大きさ・位置（最大化の状態も）は、記憶し、次の起動で、戻します。外付けの画面を外したあとなど、保存した位置が、今のどの画面にも収まらないときは、大きさだけを戻します。

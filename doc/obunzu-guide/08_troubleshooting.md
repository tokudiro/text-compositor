# こんなときは

| 困りごと | 原因と対処 |
| --- | --- |
| 起動時に、Windowsの警告が出る | コード署名をしていないためです（推測です）。配布元のReleasesから取得したことを確かめたうえで、実行してください |
| 何も表示されず、「ファイルを開く」の案内のままになる | 最初の変換に失敗しています。上の帯（または下）を見てください。エラーの内容と、原稿の行が、出ます |
| ファイルを開こうとしたら、「開けるファイル」の案内が出た | そのファイルの種類は、開けません。「文書を開く」の章の、表を見てください |
| `.txt`・`.csv`が、エラーになる | UTF-8（BOMなし）だけに対応します。エディタで、UTF-8（BOMなし）で保存し直してください |
| 大きなファイルが、途中までしか表示されない | 先頭の512 KBだけを表示します。表示の上に、案内が出ます |
| 図が、絵にならず、コードのまま出る | 言語名の綴りを確かめてください。未知の言語名は、ふつうのコードとして表示します |
| Mermaid・PlantUML・D2などの図が、初めて出るまで、少し時間がかかる | 図を描く道具の起動に、時間がかかるためです。描いた図は、キャッシュされ、2回目以降は、速くなります。インターネットからの取得は、ありません |
| 画像が表示されない | 画像のパスを、確かめてください。パスは、そのMarkdownファイルからの、相対パスです。見つからないときは、警告が出ます |
| ダークの配色で、Mermaidの図の線・文字が、見えにくい | 既知の制限です（[#209](https://github.com/tokudiro/text-compositor/issues/209)）。ライトの配色にすると、読みやすくなります |
| 保存しても、表示が更新されない | 稲妻のボタンが、オフになっていないか、確かめてください。オフのときは、`F5`で、変換し直します |
| 表示が、古い内容のままに見える | `F5`で、変換し直してください。改善しないときは、設定の「キャッシュ」を、削除してください |
| ズームを、戻したい | `Ctrl+0`、または、拡大率の表示を押します |
| 設定を、初期の状態に、戻したい | Obunzuを終了して、`%APPDATA%\Obunzu\settings.json`を、削除します |

## それでも解決しないとき

不具合や、要望は、GitHubの[Issues](https://github.com/tokudiro/text-compositor/issues)に、お知らせください。原稿の内容（公開できない情報を含む場合は、伏せてください）と、Obunzuの版（ウィンドウのタイトルに出ます）を、添えていただけると、原因を調べやすくなります。

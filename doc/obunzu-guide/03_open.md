# 文書を開く

## 開き方

次の3つの方法で、ファイルを開きます。

| 方法 | 操作 |
| --- | --- |
| ダイアログから | ツールバーの、フォルダのボタン、または`Ctrl+O`。ダイアログは、前回開いたファイルのフォルダから始まります（「設定」の章で、変えられます）。種類（文・Markdown・図・CSV）で、絞り込めます。「文」は、MarkdownとText（`.txt`）です |
| ドラッグ＆ドロップ | ファイルを、Obunzuのウィンドウに、ドロップします。複数のファイルをドロップしたときは、最初の1つを開きます |
| コマンドライン | `obunzu.exe C:\docs\memo.md` |

Obunzuが起動しているときに、別のファイルを開くと、既存のウィンドウで表示します。ウィンドウは、増えません。

文書の中の、Markdownファイルへのリンクを押すと、そのファイルを、Obunzuで開きます。Webのリンク（`https://...`）は、既定のブラウザで開きます。

## 開けるファイル

| 種類 | 拡張子 | 表示 |
| --- | --- | --- |
| Markdown | `.md`・`.markdown` | 文書として表示します。中の図も、絵にします |
| 図 | `.mmd`（Mermaid）・`.puml`・`.plantuml`・`.pu`（PlantUML）・`.d2`（D2）・`.dot`・`.gv`（Graphviz）・`.pikchr`（Pikchr） | 図1つを、表示します |
| Text | `.txt` | 等幅の素のテキストとして表示します。Markdownとしては、解釈しません |
| CSV | `.csv` | 表として表示します。1行目を見出しにするかは、切り替えられます（「画面の見方と操作」の章） |
| SVG | `.svg` | 画像として表示します |

次の点に、注意してください。

- `.txt`と`.csv`は、UTF-8（BOMなし）だけに対応します。Shift_JIS・UTF-16・BOMつきのUTF-8は、エラーになります。
- 大きなファイルは、先頭の512 KBだけを表示し、その旨を案内します。
- 上の表にないファイル（`.yaml`・`.json`・ソースコード・`.html`・SVG以外の画像・PDF・拡張子のないファイル・フォルダなど）は、開きません。エラーの帯に、開けるファイルの一覧が出ます。`.yaml`・`.json`・ソースコードの色付きの表示は、今後、対応する予定です。
- コマンドラインで指定した、存在しないファイルも、同じように、案内が出ます。

## 文書の書き方

Obunzuで表示できるMarkdownは、text-compositorが、PDFにできるMarkdownと、同じ書き方です。次の表のとおり、通常のMarkdownの記法（見出し・段落・リスト・表・引用・コード・リンク・画像・取り消し線・タスクリスト・注記）に対応します。

| 記法 | 対応 |
| --- | --- |
| 見出し・段落・リスト・引用・コード・リンク・画像 | 対応します。コードの色付けは、しません |
| 表・取り消し線・タスクリスト（`- [ ]`） | 対応します |
| 注記（`> [!NOTE]`・`> [!WARNING]`など） | 対応します |
| 文字の色・大きさ（`[text]{color=red size=14pt}`） | 対応します |
| 画像の大きさ・位置（`![alt\|width=50%](...)`） | 対応します |
| 図のコードブロック | 対応します（「図を書く」の章） |
| `:::`のレイアウトブロック | 近い見た目で表示します。PDFの見た目とは、少し違います |
| 改ページ・用紙・ヘッダー・フッターの指定 | 意味がないため、無視します |
| 生のHTML・`typst-exec` | 表示しません。警告を出します（`typst-exec`は、コードとして表示します） |
| 数式 | 対応していません |

記法の詳細と、書き方の例は、text-compositorの「使い方ガイド」（Markdownの基本・図表・カスタムテンプレートなど）を見てください。

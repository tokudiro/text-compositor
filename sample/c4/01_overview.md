# ECサイト アーキテクチャ設計書

この文書は、ECサイトの構造を、C4モデルで説明します。C4モデルは、System Context・Container・Component・Codeの4つの階層で、ソフトウェアの構造を、段階的に詳しく描く方法です。この文書では、Codeを除く、3つの階層と、実行時の流れ（Dynamic）、配置（Deployment）を示します。

すべての図は、1つのモデル（`model.dsl`）から作ります。要素や関係を直すと、すべての図に反映されます。図ごとに、同じ内容を書き写す必要はありません。

| 章 | 図 | 読み手 |
| --- | --- | --- |
| 2 | System Context | 誰でも（利用者・企画・他チーム） |
| 3 | Container | 開発者・運用担当 |
| 4 | Component | このシステムの開発者 |
| 5 | Dynamic | 開発者・運用担当 |
| 6 | Deployment | 運用担当・インフラ担当 |

# 方法

原稿は章ごとのMarkdownファイルに分け、`chapters`に並べる。表や箇条書きは、通常のテンプレートと同じ記法で書ける。

| 項目 | 内容 |
|------|------|
| 段組み | 2段 |
| タイトル | 全幅 |
| 概要 | `document.abstract` |

## 制約

- 章ごとの改ページは行わない。`<!-- pagebreak -->`による明示の改ページも効かない。
- 段幅より広い表やコードは、折り返されるか、はみ出す。

# おわりに

2段組みの論文形式を、`template.path: paper`で使えることを示した。
